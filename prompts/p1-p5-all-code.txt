### 17. engine/camera/CameraSource.kt

### 18. engine/facedetect/FaceDetector.kt
- Wraps MediaPipe FaceLandmarker
- Create from bundled model file (copy from assets or download from MediaPipe)
- suspend fun detect(frame: Frame): FaceResult?
- FaceResult: noseTip, leftEye, rightEye, mouthLeft, mouthRight (normalized 0-1 coordinates as Pair<Float,Float>)
- Fallback: if model not available, return null and log warning
- Handle no-face gracefully

### 19. engine/angle/AngleCalculator.kt
- Input: FaceResult + phone rotation vector
- Algorithm: approximate head pitch from face landmark geometry
  - If both eyes visible: pitch from eye-mouth vertical ratio
  - If full profile: pitch from nose-ear offset
  - If only partial face: use nose vertical position relative to face bounding box
- Combined with phone IMU pitch → estimated head angle
- Output: AngleResult(angleDeg: Float, confidence: Float)
- confidence: 0.0-1.0 based on landmark visibility

### 20. engine/angle/PostureClassifier.kt
- Uses accelerometer to detect posture mode
- Stand/sit: gravity z ~9.8, x/y ~0
- Lying supine: gravity y ~9.8, z ~0
- Lying side: gravity x ~9.8, others ~0
- Smooth over 2-second window (running average)
- postureMode: StateFlow<PostureMode> (STANDING, SITTING, LYING_SUPINE, LYING_SIDE, UNKNOWN)
- start() / stop() for sensor listener

### 21. engine/angle/MonitorEngine.kt
- Singleton coordinator
- Combines CameraSource + FaceDetector + AngleCalculator + IMU/PostureClassifier
- monitorState: StateFlow<MonitorState>
- MonitorState data class: angle, postureMode, isFaceDetected, badPostureDuration, isBadPosture
- When face lost: keep last angle for 2s, then set angle to null
- start() / stop()
- Runs in coroutine scope, launches a loop that:
  1. Takes frame from CameraSource.frameFlow
  2. Calls FaceDetector.detect()
  3. If face found: calls AngleCalculator
  4. Updates monitorState
  5. Throttles based on frame rate mode

### 22. engine/alert/AlertEngine.kt
- Subscribes to MonitorEngine.monitorState
- When angle > threshold for > duration_threshold consecutive seconds:
  - Fire alert if cooldown elapsed
- Vibration patterns:
  - single: 300ms
  - double_short: 200ms, 200ms gap, 200ms
  - long: 1000ms
  - pulse: 100ms, 100ms gap (repeat 3x)
- Uses Vibrator + VibrationEffect (API 26+)
- alertFlow: SharedFlow<AlertEvent>
- start() / stop() / updateConfig()

```kotlin
    val timestamp: Long,
    val angle: Float,
    val postureMode: String,
    val isBadPosture: Boolean,
    val durationSeconds: Int

@Entity(tableName = "settings")
data class AppSettings(
    @PrimaryKey val id: Int = 1,
    val angleThreshold: Float = 25f,
    val durationThreshold: Int = 15,
    val cooldownSeconds: Int = 30,
    val vibrationPattern: String = "double_short",
    val frameRateMode: String = "balanced"
)
```
