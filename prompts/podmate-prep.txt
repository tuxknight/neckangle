### 4. Initialize git repo, add remote, commit and push

Steps:
1. cd /home/pi/hermes-workspace/podmate
2. git init
3. git checkout -b main
4. Apply all file changes above
5. git add -A && git commit -m "init: PodMate podcast CLI tool"
6. git remote add origin https://github.com/tuxknight/podmate.git
7. git push -u origin main

If HTTPS push fails with SSL errors on this RPi, try:
- git config --global http.sslVerify false
- If that still fails, use SSH if configured, or use the GitHub API to create blobs/trees/commits

Goal: all code is on GitHub at github.com/tuxknight/podmate with no sensitive data in the repo.
